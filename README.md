# Picture Grid Guide

이미지에 정교한 그리드(Grid) 가이드 라인을 그려주고 결과물을 고해상도 PNG 파일로 직접 다운로드할 수 있는 프리미엄 웹 도구입니다.

## 🌟 주요 기능

- **고급스러운 UI 디자인**: 다크 모드 및 Glassmorphism 스타일이 적용된 세련된 인터페이스.
- **실시간 렌더링**: 가로/세로 그리드 분할 개수(1~25), 선 두께, 선 색상을 변경할 때마다 실시간으로 캔버스에 즉각 피드백.
- **강력한 호환성**: 프레임워크 의존성 없이 순수 HTML/JS/CSS만으로 작성되어 모든 모던 웹 브라우저에서 안전하고 빠르게 작동합니다.
- **안정적인 다운로드**: 다운로드 권한 오류나 확장자 무시 이슈를 해결하기 위해 브라우저의 기본 기능을 최대한 활용하며, 수동 다운로드 기능도 완벽히 지원합니다.
- **직관적인 조작**: 클릭 또는 드래그 앤 드롭을 통한 간편한 파일 업로드 지원.

## 🚀 사용 기술

- **HTML5**: 구조 설계 (Canvas API 활용)
- **CSS3**: 스타일링 및 반응형 디자인 (Vanilla CSS)
- **JavaScript (ES6)**: 이미지 프로세싱 및 UI 상태 관리 (순수 JS)

## 🛠 사용 방법

별도의 설치나 빌드 과정이 필요하지 않습니다.

1. 이 저장소의 파일을 다운로드 받거나 클론합니다.
2. `index.html` 파일을 크롬, 엣지, 사파리 등의 웹 브라우저로 엽니다.
3. 작업할 이미지를 화면에 드래그하여 놓거나 클릭하여 업로드합니다.
4. 왼쪽 컨트롤 패널을 사용하여 그리드를 원하는 대로 조절합니다.
5. **[💾 이미지 다운로드]** 버튼을 클릭하여 결과물을 저장합니다.
   *자동 다운로드가 되지 않을 경우 중앙의 작업 이미지를 우클릭하여 '이미지를 다른 이름으로 저장'할 수 있습니다.*

## 🌐 호스팅 및 배포 (GitHub Pages)

이 프로젝트는 정적 파일(HTML) 1개로 구성되어 있으므로 **GitHub Pages**를 통해 매우 쉽게 배포할 수 있습니다.

1. GitHub 저장소의 **Settings**로 이동합니다.
2. 왼쪽 메뉴에서 **Pages**를 클릭합니다.
3. Source (Build and deployment)에서 `Deploy from a branch`를 선택하고 branch를 `main`(또는 `master`), `/(root)` 폴더로 설정한 뒤 **Save**를 누릅니다.
4. 잠시 후 안내되는 웹 주소(URL)를 통해 누구나 접속할 수 있습니다.
